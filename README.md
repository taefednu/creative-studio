# Mentorium Creative Studio

Безопасная творческая соцсеть для детей 5–12 лет: ребёнок создаёт картинки и короткие истории с
помощью моделей Meta (Muse Spark, Muse Image, SAM 3.1), делится в ленте класса и ремиксит. Модель
только классифицирует, решает код; сомнение уходит учителю. Аккаунты и монеты — из платформы
Mentorium. Сделано для Meta Global AI Developer Hackathon (сдача 4.11.2026 21:00 ET).

Статус: инфраструктура и база знаний, кода продукта пока нет.

## Карта

| Путь | Что |
|------|-----|
| `CLAUDE.md` | правила для Claude Code; читается каждой сессией |
| `knowledge/` | база знаний: факты, решения, открытые вопросы, архитектура, sprint |
| `.claude/` | агенты, хуки, правила по частям дерева, `settings.json` |
| `backend/` | FastAPI (пусто) |
| `frontend/` | React + Vite (пусто) |
| `evals/` | размеченный набор безопасности и метрики (формат в `evals/README.md`) |

## Как начинать сессию

1. Открой репо в Claude Code: `CLAUDE.md` подтянется сам.
2. Прочитай верхний раздел project notes и project notes.
3. Продолжай с промпта оттуда. Цикл: `/grilling` -> `/to-spec` -> `/to-tickets` в одной сессии, затем
   `/autopilot semi strict` в новой.
