# Макеты Mentorium Creative Studio

Светлая тема — основная (решение 29.10.2026, project notes). Айдентика — детский кабинет
платформы Mentorium (Nunito, лавандовый фон, фиолетовые кнопки капсом, монеты и звёзды, робот);
раскладка — по разбору Higgsfield (`higgsfield-study.md`). Нарисовано Codex по образцам; это ориентир
для вёрстки, а не пиксельный макет: логотип в коде — настоящий файл платформы, тексты — i18n ru/en/uz.

| Файл | Экран |
|---|---|
| `feed.jpg` | лента класса: верхнее меню, «кирпичная» сетка, задание учителя строкой, панель «Создать» |
| `work.jpg` | работа поверх ленты: идея, стиль, модель, реакции, «Нарисовать так же» |
| `create.jpg` | «Создать»: веер превью, 8 стилей, задание учителя, панель |
| `result.jpg` | результат (2 варианта) и мягкий отказ «Давай нарисуем по-другому», монета вернулась |
| `kinder.jpg` | комментарии и «Скажи добрее?» |
| `login.jpg` | вход: ребёнок (ник + картинка-пароль) / родитель / учитель / «Войти через Mentorium»; код класса — после входа |
| `parent.jpg` | кабинет родителя: дети и монеты, «+ Добавить монеты» (скоро), неделя ребёнка, «Ждёт вашего OK», привязка ребёнка Mentorium по коду |
| `teacher.jpg` | учитель (выложенное в класс): «Задержано» с причинами, одобрить/отклонить, срочное сверху, размытое лицо |

Известные расхождения со спекой, править при вёрстке: на `teacher.jpg` срочная строка подписана «Personal
info» — должна быть пометка самочувствия без текста и без кнопки «Approve» (только «Открыть»); на
`create.jpg` нет иконки ⚙ — формат и «×2» в макете видны отдельно.
