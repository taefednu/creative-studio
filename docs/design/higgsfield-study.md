# Разбор Higgsfield: что берём для детей

Снято 29.10.2026 на higgsfield.ai без аккаунта (лента Community → Shots, карточка работы, экран создания
картинки, главная). Снимки в репо не кладём: на них фото реальных людей, а репо будет публичным.
Берём приёмы, а не бренд: цвета, шрифты и логотип у нас от Mentorium (см. макеты `home-*.png`).

## Что увидели

| Экран | Как устроено у Higgsfield |
|---|---|
| Навигация | только верхняя полоса, сайдбара нет; мелкие текстовые пункты, активный — акцентом |
| Лента (Shots) | плотная «кирпичная» сетка из 5 колонок, работы разной формы (вертикальные, горизонтальные), зазор ~6 px, скругление ~8 px. **На карточке нет текста** — только маленький аватар автора в углу. Сверху крупный заголовок по центру, справа фильтр «All shots ▾» и поиск |
| Карточка работы | открывается поверх ленты: картинка слева на размытом фоне, справа панель: автор, вкладки «Info / Comments», промпт с кнопкой «Copy», детали (модель, качество, размер, дата), главная кнопка-действие, ниже «Recreate» (повторить по чужому промпту) и «Download», иконки лайка, «поделиться», «ещё» |
| Создание | пустой экран: веер из 3–4 наклонённых превью, двухстрочный заголовок (вторая строка акцентом), подпись; подсказка-пилюля «Не знаешь, с чего начать?». Панель внизу по центру: сверху поле, под ним строка мелких чипов (+ файл, @ персонаж, модель, формат, качество, размер, кол-во 1/4), справа **большая квадратная кнопка «GENERATE» с ценой** на две строки |
| Discovery | большой «выбранный» проект в рамке, карусель; «Featured creators» — круглые аватары в фигурных рамках с бейджами; конкурсы с призами; гранты |
| Пресеты | «кирпичная» витрина работ по пресету + кнопки «Start generating» / «View all presets» |
| Типографика | узкий гротеск капсом для заголовков разделов, мелкие серые подписи, один акцентный цвет |

## Что берём в Mentorium Creative Studio

| Приём Higgsfield | У нас |
|---|---|
| Без сайдбара, верхняя полоса | вариант `home-nosidebar-*.png` |
| Лента без текста на карточках, разная форма работ | «кирпичная» сетка, на карточке только аватар и сердечко с числом |
| Карточка поверх ленты с промптом | промпт ребёнка (уже проверенный), стиль, модель; реакции; комментарии со «Скажи добрее?» |
| **Recreate** | **«Нарисовать так же»** — ремикс из заявки (#10): тот же шаблон и промпт, свои слова |
| Панель создания: поле + строка чипов + большая кнопка с ценой | поле, микрофон, модель, стиль, ⚙ (формат, кол-во); кнопка «CREATE» с монетой и ценой |
| Пустой экран создания с веером превью | веер из 3–4 работ шаблонов + «Что нарисуем сегодня?» + пилюля «Не знаешь, с чего начать? → Шаблоны» |
| Featured creators | «Звёзды класса» за неделю — в рамках как значки платформы (без рейтинга «лучший/худший») |
| Конкурсы | **задания учителя** — «конкурс» внутри класса со сроком |

## Что не берём

- Чёрный фон + салатовый, узкие капс-заголовки — у нас айдентика Mentorium (Nunito, индиго, фиолетовый).
- Фото реальных людей, «Turn to video», гранты и денежные призы.
- Мелкие технические чипы (качество, разрешение) — ребёнку не нужны; формат и количество спрятаны под ⚙.
- Копирование промпта чужого ребёнка как текста — вместо этого «Нарисовать так же».
